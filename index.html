Firebase hesabı ve senkronizasyon

Bağlantı kontrol ediliyor

E-posta/şifre ile hesap açabilir veya Google hesabınla giriş yapabilirsin. Giriş yaptığında uygulama verilerin Firestore hesabına kaydedilir. Dosyalar ve ekler cihazında kalır; Firebase Storage kullanılmaz.

Firebase hesabıyla giriş için HTTPS veya localhost gerekir. file:// üzerinden açıldığında Firebase girişi çalışmayabilir; oturumsuz kullanım yine yerel olarak kullanılabilir.
-
Firebase hesabı bağlı
Giriş yapmadan önce kayıtların bu cihazda tutulur. Giriş yaptığında yerel kayıtları buluta yükleme veya buluttaki kayıtları kullanma seçeneği sunulur.
Son senkronizasyon: Henüz yok
Otomatik senkronizasyon açıkken yerel değişiklikler kısa bir beklemeden sonra buluta gönderilir. Aynı hesap başka cihazda değiştirildiyse üzerine yazmadan önce uyarı gösterilir.
Senkronizasyon çakışması

Bu cihazdaki ve buluttaki kayıtların ikisi de son senkronizasyondan sonra değişmiş. Hangi kopyayı kullanmak istediğini seç.

Veri ve gizlilik

Görev, sınav, konu, ders, not ve çalışma kayıtları yerel olarak saklanır; Firebase hesabına giriş yapıldığında uygulama verileri Firestore ile senkronize edilebilir. Dosya içerikleri, ekler ve dosya verileri buluta gönderilmez. Tarayıcı verilerini silmeden önce JSON yedeği indir.

Firestore güvenlik kuralları

V15

Bu uygulama veriyi users/{uid}/appData/main yolunda saklar. Aşağıdaki kurallar her hesabın yalnızca kendi ana belgesini okumasına ve yazmasına izin verir. Diğer tüm yollar kapalıdır.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/appData/{docId} {
      allow get: if request.auth != null
                 && request.auth.uid == userId
                 && docId == 'main';
      allow list: if false;
      allow create, update: if request.auth != null
                            && request.auth.uid == userId
                            && docId == 'main'
                            && request.resource.data.keys().hasOnly([
                              'data', 'updatedAt', 'schemaVersion'
                            ])
                            && request.resource.data.data is map;
      allow delete: if false;
    }
    // Herhangi bir eşleşmeyen belge için erişim verilmez.
  }
}
Kurallar otomatik yayımlanmaz. Firebase Console → Firestore Database → Rules bölümüne yapıştırıp yayımlamalısın. Önce doğru Firebase projesinde olduğunu kontrol et. Bu kurallar veli hesabına başka öğrencinin verisini açmaz.

Not: Bu kurallar uygulamanın mevcut kullanıcı başına tek belge yapısına göredir. İleride yeni koleksiyonlar eklenirse ayrıca kural yazılmalıdır. Firestore belgeleri 1 MiB sınırını aşamaz; büyük dosyaları uygulama buluta yüklemez.

Servis ve güvenlik notları

Bu sürüm Firebase Authentication ve Cloud Firestore kullanır. Cloud Storage, Cloud Functions ve Firebase Hosting kullanılmaz. PWA olarak HTTPS üzerinden yayınlandığında uygulama arayüzü çevrimdışı açılabilir; kayıtlar cihazda tutulur ve bağlantı gelince senkronizasyon kuyruğu işlenebilir. Yönetici yetkisi atama ve gerçek veli-öğrenci hesap bağlantısı bu sürümde etkin değildir. V13 aile tercihleri yalnızca yerel ayardır. V15 Firestore kuralları Ayarlar bölümünde kopyalanabilir; Firebase Console'da elle yayımlanmalıdır. V16.1.1 Beta 2: İlk açılış hesap ekranı, oturumsuz devam, oturum açık kalsın tercihi ve Firebase oturum kalıcılığı seçimi eklendi. Firebase Authentication için HTTPS/localhost gerekir; file:// üzerinden giriş desteklenmez. Premium özellikler test sonrası belirlenecek. Google ile giriş için Firebase Console'da Google sağlayıcısını etkinleştirip GitHub Pages alan adını yetkili alan adlarına eklemelisin.
